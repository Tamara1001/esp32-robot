# CONTRIBUTING

Proyecto personal; estas reglas mantienen el orden.

1. Leer [CODESTYLE.md](CODESTYLE.md) y [STRUCTURE.md](STRUCTURE.md).
2. Crear rama `feat/<tema>` desde `main`.
3. Commits con Conventional Commits.
4. Antes de mergear: compilar el sketch en Arduino IDE y probar la web en un celular.
5. Actualizar docs (`DESIGN.md`, `docs/PROTOCOL.md`, `docs/HARDWARE.md`) si cambian pines, protocolo o arquitectura.
6. Marcar el avance en [ROADMAP.md](ROADMAP.md).
